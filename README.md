# ⚡ TEXORA | تكسورا للأنظمة الرقمية والبرمجيات المتطورة

موقع ونظام شركة **Texora** المتخصص في هندسة وتطوير الأنظمة البرمجية الفائقة، المنصات التعليمية، أنظمة إدارة الصيدليات والمتاجر، وبوتات الذكاء الاصطناعي المؤتمتة على الواتساب.

---

## 🌟 مميزات النظام والمنصة (System Highlights)

1. **تجربة إبهار بصري ثلاثية الأبعاد (3D Scrollytelling Experience):**
   - شعار الشركة في المنتصف بتقنية ثلاثية الأبعاد (Three.js WebGL) متفاعل مع حركة الماوس والجاذبية.
   - عند بدء التمرير، يتفادى النص إلى أقصى اليمين وأقصى اليسار مع نزول الشعار ببعد ثلاثي الأبعاد عميق.
   - في منتصف التمرير، ينتقل الشعار بسلاسة إلى الجانب ليتحول إلى حرف **T**، وتظهر خلفه شاشة بيضاء مميزة فاخرة (`brand-white-stage`) لتكتمل بقية حروف اسم الشركة **TEXORA** بتأثير معدني كرومي.
   - بعد انتهاء المشهد، يثبت الشعار في القائمة العلوية (`sticky navbar`).

2. **الترسانة التقنية والأنظمة الأساسية:**
   - **PharmaCare Pro:** نظام سحابي لإدارة الصيدليات مع كشف بدائل الأدوية بالمادة الفعالة، تنبيهات تواريخ الصلاحية، والجرد بالباركود.
   - **RetailFlow POS:** نظام متكامل لمتاجر وبرندات الملابس مع ربط الفروع ومزامنة المخزون اللحظية.
   - **EduVerse LMS:** منصات تعليمية تفاعلية مع حماية قصوى للفيديوهات ضد التصوير (DRM) وامتحانات ذاتية التصحيح.
   - **Enterprise Web Platforms:** مواقع وتطبيقات ويب سحابية بهندسة Cloudflare Edge فائقة السرعة.
   - **Texora AI Assistant:** بوت واتساب مؤتمت يعمل 24/7 بدون موظف لتأهيل العملاء وتقديم عروض الأسعار وحجز المواعيد.

3. **بيئة تجربة حيّة (Interactive Live Sandbox):**
   - محاكي كاشير ونقاط بيع تفاعلي بالباركود وطباعة إيصال بيع حراري.
   - محاكي منصة تعليمية بفيديو محمي وعلامة مائية متحركة واختبار تفاعلي فوري.
   - محاكي هاتف ذكي لمحادثة بوت الواتساب الذكي مباشرة داخل المتصفح.

4. **محرك تسعير المشاريع الذكي (Cost & Scope Estimator):**
   - يتيح للعميل اختيار النظام، النطاق، والإضافات التقنية مع حساب فوري للتكلفة والمدة ورابط حجز مباشر عبر الواتساب.

---

## 🏗️ البنية التحتية والربط السحابي (Cloud Architecture)

- **Frontend & Web Platform:** React 19 + TypeScript + Tailwind CSS v4 + Three.js + Lucide (Deployed on **Cloudflare Pages**).
- **Database & Storage:** **Supabase PostgreSQL** (`/supabase/migrations/20261108_init_texora.sql`).
- **AI WhatsApp Bot Microservice:** **Vercel Serverless Edge** (`/api/whatsapp/webhook.ts` + `vercel.json`).

## 🚀 أوامر التشغيل والبناء (Local & Deployment Commands)

### 1. التشغيل المحلي (Development Server):
```bash
npm run dev
```

### 2. البناء للإنتاج (Production Build):
```bash
npm run build
```

### 3. النشر على Cloudflare Pages:
```bash
npx wrangler pages deploy dist --project-name=texora-systems
```

### 4. النشر على Vercel (لبوت الواتساب والـ Serverless API):
```bash
npx vercel --prod
```
